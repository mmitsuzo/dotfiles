# dotfiles

## config files

- `~/.config/vim/vimrc`
- `~/.config/bash/bashrc` (need to be read from `~/.bashrc`)

## scripts

- `scripts/install.sh`
  - install config files
- `scripts/setup-vim.sh`
  - install external tools required by vim
    - plugin manager
    - skk dictionary
- `scripts/setup-git-bash-win.sh`
  - set windows-specific config/environment
