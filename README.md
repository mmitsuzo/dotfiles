# dotfiles

## config files

- `~/.bashrc`
    - just read `~/.config/bash/bashrc`
- `~/.config/bash/bashrc`
- `~/.config/vim/vimrc`

## scripts

- `scripts/install.sh`
    - install config files
- `scripts/install-*.sh`
    - install programs (windows environment assumed)
- `scripts/setup-git-bash-win.sh`
    - set windows-specific config/environment
